## فونت ایران‌سنس

ایران‌سنس فونت تجاری (فونت‌ایران) است و فایل‌هایش در مخزن قرار نمی‌گیرند.
فایل‌های دارای مجوز (`.woff2` / `.woff` / `.ttf`، مثلاً `IRANSansWeb(FaNum)_Bold.woff2`) را در `fonts/iransans/` بگذارید و اجرا کنید:

```
node render.js
```

وزن هر فایل از نامش تشخیص داده می‌شود (Light، Medium، Bold، Black و…) و نسخه‌ی FaNum در اولویت است.
بدون فایل‌های ایران‌سنس، `node render.js --fallback` با فونت وزیرمتن خروجی می‌گیرد.
